# ÉLARA - Timeless Fashion E-Commerce Website


## 🌟 Introduction

**ÉLARA** is a modern, elegant, and fully responsive e-commerce website designed to deliver a premium online shopping experience. The platform focuses on timeless fashion, combining minimal aesthetics with powerful features like cart management, wishlist, and secure checkout.

---

## 🎯 Project Objective

The goal of this project is to build a real-world e-commerce platform where users can:

* Browse and explore products
* Add items to cart or wishlist
* Securely place orders
* Manage their shopping experience through authentication

---

## 🛍️ Features

### 🔹 Core E-Commerce Functionalities

* 🛒 Add to Cart – Users can add/remove products and manage quantity
* ❤️ Wishlist – Save favorite products for later
* 💳 Checkout System – Smooth checkout flow with order summary
* 📦 Order Details Page – View placed orders and product details
* 🔐 Authentication – Login & Signup functionality

---

### 🔹 User Interface & Experience

* Clean and modern UI design
* Smooth animations and hover effects
* Premium typography and color scheme
* Toast notifications for actions (Add to cart, Wishlist, etc.)

---

### 🔹 Product Management

* Category-based product browsing
* Product cards with:

  * Image
  * Price & discount
  * Ratings & reviews
  * Description

---

### 🔹 Responsiveness

* Fully responsive across:

  * 📱 Mobile
  * 💻 Tablet
  * 🖥 Desktop

---

### 🔹 Performance

* Fast loading and optimized UI
* Lightweight structure
